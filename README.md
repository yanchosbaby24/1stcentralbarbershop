# 1st Central Barbershop – strona internetowa

Strona internetowa 1st Central Barbershop we Wrocławiu.

## Kontakt
- **Adres:** Kotlarska 29, 50-120 Wrocław, Polska
- **Telefon:** 505 726 791
- **Godziny otwarcia:** poniedziałek–sobota, 10:00–20:00
- **Niedziela:** zamknięte
- **Rezerwacje:** [Booksy](https://booksy.com/pl-pl/166270_1st-central-barbershop_barber-shop_13750_wroclaw)
- **Google Maps:** [1st Central Barbershop](https://www.google.com/maps/place/Kotlarska+29,+50-120+Wrocław,+Poland)

## Usługi i ceny
- Strzyżenie klasyczne – 100 PLN
- Strzyżenie długich włosów – 130 PLN
- Strzyżenie samymi nożyczkami – 110 PLN
- Strzyżenie brody – 70 PLN
- Pakiet Combo (włosy + broda) – 140–170 PLN
- Fade i Buzz Cut – 80 PLN
- Happy Hours 10:00–14:00: strzyżenie 90 PLN, Combo 130 PLN

## Zespół
Yana, Warja, Kostja oraz Valera.

## Technologie
Strona korzysta z HTML, CSS i JavaScript. Jest responsywna i działa na telefonach, tabletach oraz komputerach.

## Aktualizacja strony
Zmiany wprowadzone w repozytorium GitHub zostaną opublikowane na GitHub Pages po chwili. Plik `index.html` zawiera treści strony, `styles.css` odpowiada za wygląd, a `script.js` za interakcje.
